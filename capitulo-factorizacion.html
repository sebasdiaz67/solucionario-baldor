📖 Factorización

Capítulo - 10 ejercicios disponibles

Ejercicio F001 1/10
Problema: $x² + 6x + 9$

📝 Pasos de la Solución:

1. Reconocer trinomio cuadrado perfecto
2. Verificar si es (a + b)² = a² + 2ab + b²
3. a² = x² → a = x
4. b² = 9 → b = 3
5. 2ab = 2·x·3 = 6x ✓
6. Por lo tanto: (x + 3)²
💡 Solución Final: $(x + 3)²$
Ejercicio F002 2/10
Problema: $x² - 25$

📝 Pasos de la Solución:

1. Reconocer diferencia de cuadrados
2. Verificar si es a² - b² = (a + b)(a - b)
3. a² = x² → a = x
4. b² = 25 → b = 5
5. Por lo tanto: (x + 5)(x - 5)
💡 Solución Final: $(x + 5)(x - 5)$
Ejercicio F003 3/10
Problema: $2x² + 8x$

📝 Pasos de la Solución:

1. Extraer factor común
2. Identificar el máximo común divisor: 2x
3. 2x² ÷ 2x = x
4. 8x ÷ 2x = 4
5. Por lo tanto: 2x(x + 4)
💡 Solución Final: $2x(x + 4)$
Ejercicio F004 4/10
Problema: $x² + 5x + 6$

📝 Pasos de la Solución:

1. Factorizar trinomio de la forma x² + bx + c
2. Buscar dos números que multipliquen c = 6 y sumen b = 5
3. Los números son 2 y 3
4. Verificar: 2 × 3 = 6 y 2 + 3 = 5 ✓
5. Por lo tanto: (x + 2)(x + 3)
💡 Solución Final: $(x + 2)(x + 3)$
Ejercicio F005 5/10
Problema: $x² - 7x + 12$

📝 Pasos de la Solución:

1. Factorizar trinomio de la forma x² + bx + c
2. Buscar dos números que multipliquen c = 12 y sumen b = -7
3. Los números son -3 y -4
4. Verificar: (-3) × (-4) = 12 y (-3) + (-4) = -7 ✓
5. Por lo tanto: (x - 3)(x - 4)
💡 Solución Final: $(x - 3)(x - 4)$
Ejercicio F006 6/10
Problema: $3x² - 12$

📝 Pasos de la Solución:

1. Extraer factor común: 3
2. 3(x² - 4)
3. Reconocer diferencia de cuadrados en x² - 4
4. x² - 2² = (x + 2)(x - 2)
5. Por lo tanto: 3(x + 2)(x - 2)
💡 Solución Final: $3(x + 2)(x - 2)$
Ejercicio F007 7/10
Problema: $x³ + 8$

📝 Pasos de la Solución:

1. Reconocer suma de cubos: a³ + b³ = (a + b)(a² - ab + b²)
2. a³ = x³ → a = x
3. b³ = 8 → b = 2
4. Por lo tanto: (x + 2)(x² - 2x + 4)
💡 Solución Final: $(x + 2)(x² - 2x + 4)$
Ejercicio F008 8/10
Problema: $x³ - 27$

📝 Pasos de la Solución:

1. Reconocer diferencia de cubos: a³ - b³ = (a - b)(a² + ab + b²)
2. a³ = x³ → a = x
3. b³ = 27 → b = 3
4. Por lo tanto: (x - 3)(x² + 3x + 9)
💡 Solución Final: $(x - 3)(x² + 3x + 9)$
Ejercicio F009 9/10
Problema: $4x² - 9y²$

📝 Pasos de la Solución:

1. Reconocer diferencia de cuadrados
2. 4x² = (2x)² → a = 2x
3. 9y² = (3y)² → b = 3y
4. Por lo tanto: (2x + 3y)(2x - 3y)
💡 Solución Final: $(2x + 3y)(2x - 3y)$
Ejercicio F010 10/10
Problema: $x² + 8x + 16$

📝 Pasos de la Solución:

1. Reconocer trinomio cuadrado perfecto
2. Verificar si es (a + b)² = a² + 2ab + b²
3. a² = x² → a = x
4. b² = 16 → b = 4
5. 2ab = 2·x·4 = 8x ✓
6. Por lo tanto: (x + 4)²
💡 Solución Final: $(x + 4)²$
